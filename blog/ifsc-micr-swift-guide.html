🏦 IFSC vs MICR vs SWIFT Code — What's the Difference?

All three identify a bank, but for three completely different kinds of transfer. Here's which one you actually need.

📅 Updated July 2026⏱ 5 min read

Why three different codes exist

It's easy to assume these are interchangeable since all three "identify a bank," but each one was built for a different payment network with different rules, and none of them can be calculated from the others.

IFSC — for domestic Indian transfers

The Indian Financial System Code is an 11-character code (4 letters for the bank, then a fixed "0", then 6 characters identifying the specific branch) used by India's own transfer networks — NEFT, RTGS and IMPS. It's branch-specific: two branches of the same bank will share the first 4 letters but have different IFSC codes overall. You'll find it printed on your chequebook, passbook, or in your net-banking portal's account details page.

MICR — for physical cheque processing

The Magnetic Ink Character Recognition code is a 9-digit number printed at the bottom of a physical cheque in special magnetic ink, so cheque-sorting machines at banks can read it automatically. It identifies the city, the bank, and the branch — but it has nothing to do with online transfers; you'll never be asked for a MICR code on a UPI or NEFT form. It only matters if you're dealing with a physical cheque.

SWIFT / BIC — for international wire transfers

The SWIFT (or BIC) code is 8 or 11 characters and identifies a bank for cross-border wire transfers — it's what someone overseas needs to send money into an Indian account, or what you need to send money out. Unlike IFSC, SWIFT codes are often assigned at the bank level rather than per-branch, since international transfers route to a bank's main gateway first.

What about UPI?

UPI needs none of these — it identifies an account using a UPI ID (like name@bank) or a linked mobile number instead, which is why UPI transfers skip the IFSC step entirely.

Common mistakes

  • Typing the letter "O" instead of the digit "0" as the 5th character of an IFSC code — a very common typo since they look identical in many fonts.
  • Using an old bank's IFSC after a merger. When banks merge (for example, several public-sector bank mergers in recent years), old branch IFSC codes may stop working — always confirm the current one with your bank if a cheque or old document looks outdated.
  • Assuming a bank's SWIFT code can be derived from its IFSC. They're separate systems maintained by separate authorities (RBI for IFSC, a bank's own treasury/forex desk for SWIFT) — one cannot be computed from the other.
