🐦 What are Twitter Cards?

Twitter Cards are special meta tags that allow rich media to be attached to tweets. When someone shares a URL that has Twitter Card tags, the tweet automatically displays a card below the text — showing a title, description, image or even a video player.

There are 4 Twitter Card types: summary_large_image (a large banner image — most popular for blogs and news), summary (a compact card with a small thumbnail), app (for mobile app promotion linking directly to App Store / Play Store), and player (for embedded audio or video).

Which Card Type Should I Use?

  1. summary_large_image — Blogs, news articles, product pages. Highest engagement.
  2. summary — Homepages, profile pages, pages without a hero image.
  3. app — Mobile app landing pages with App Store / Play Store links.
  4. player — Pages with embedded video or podcast audio.

How to Install

  1. Fill in the form and click Generate Tags.
  2. Copy the generated HTML.
  3. Paste inside the <head> of your HTML page.
  4. Test with Twitter Card Validator at cards-dev.twitter.com/validator.
  5. Clear Twitter's cache if a URL was previously shared without cards.

Twitter Cards vs Open Graph tags | Twitter Cards बनाम Open Graph tags

Open Graph (og:) tags were built for Facebook but are now read by most platforms as a fallback, including X when a dedicated twitter: tag is missing. Twitter Cards exist separately because X supports extra card types — app-promotion cards and player cards for embedded video/audio — that Open Graph has no equivalent for, and because X sometimes needs a different crop or character limit than Facebook. The safest approach, which this generator encourages, is to set both: Open Graph tags for general link sharing, and Twitter Card tags tuned specifically for X's display rules. | Open Graph (og:) tags मूल रूप से Facebook के लिए बने थे, पर अब ज़्यादातर platforms इन्हें fallback के रूप में पढ़ते हैं, जिसमें X भी शामिल है जब कोई dedicated twitter: tag मौजूद न हो। Twitter Cards अलग से मौजूद हैं क्योंकि X कुछ extra card types support करता है — app-promotion cards और embedded video/audio के लिए player cards — जिनके लिए Open Graph में कोई बराबर option नहीं है। सबसे सुरक्षित तरीका, जिसे यह generator बढ़ावा देता है, दोनों set करना है: सामान्य sharing के लिए Open Graph, और X के नियमों के हिसाब से tuned Twitter Card tags।

Choosing the right card type | सही card type चुनना

The four types serve different purposes: summary_large_image dominates the tweet with a wide banner and suits blog posts, news and product pages; summary uses a small square thumbnail suited to profile or homepage links; app links straight to an App Store or Play Store listing and should only be used on app landing pages; and player embeds a video or audio player inside the tweet itself. Picking the wrong type is a common mistake — using "app" on a regular blog post, for instance, strips away the title and description entirely and shows only a download button. | चार types अलग-अलग मक़सद के लिए हैं: summary_large_image एक बड़ी banner image के साथ पूरे tweet पर हावी रहता है और blog posts, news और product pages के लिए सही है; summary एक छोटी square thumbnail इस्तेमाल करता है जो profile या homepage links के लिए उपयुक्त है; app सीधे App Store या Play Store listing से जोड़ता है और सिर्फ़ app landing pages पर इस्तेमाल होना चाहिए; और player tweet के अंदर ही video या audio player embed करता है। गलत type चुनना एक सामान्य गलती है — जैसे किसी normal blog post पर "app" इस्तेमाल करना title और description पूरी तरह हटा देता है।

Q. Why isn't my card showing up after I tweeted the link? | Link tweet करने के बाद card क्यों नहीं दिख रहा?

Q. Do I still need Open Graph tags if I add Twitter Cards? | अगर Twitter Cards add कर दिए तो क्या Open Graph tags भी चाहिए?

Q. What's the character limit for the title and description? | Title और description की character limit क्या है?
