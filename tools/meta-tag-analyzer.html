🔍 What is Meta Tag Analyzer?

The Meta Tag Analyzer is a free SEO tool that reads any webpage's HTML source code and extracts every meta tag — then grades each one against Google's best practices. In one click, you get a full report covering your title tag, meta description, canonical URL, Open Graph tags, Twitter Card tags, robots directives, language, charset, viewport, author, theme color, and more.

Unlike tools that require a live URL (which often get blocked by CORS or server restrictions), this analyzer works entirely in your browser using the raw HTML you paste in. Just open any webpage, press Ctrl+U (View Source), select all, paste here, and hit Analyze. You get an instant, completely private report — nothing is sent to any server.

What Does the Score Mean?

The SEO score (0–100) is calculated based on the presence and quality of critical meta tags. A score above 80 means your page's meta tags are well-optimized. 50–79 means there are gaps to fix. Below 50 means important tags are missing or incorrectly formatted.

How to Use

  1. Open any webpage in your browser and press Ctrl+U to view source.
  2. Press Ctrl+A to select all, then Ctrl+C to copy.
  3. Paste the HTML into the box above and click Analyze Tags.
  4. Review the score, SERP preview, OG preview, and each tag's status.
  5. Fix any tags marked ❌ or ⚠️ and re-analyze to confirm.
  6. Download the report as a text file to share with your team.

About This Tool | इस टूल के बारे में

The Meta Tag Analyzer reads the raw HTML source of any webpage and extracts every SEO-relevant meta tag — title, description, canonical, robots, viewport, charset, language, Open Graph and Twitter Card tags — then grades the page with a 0–100 SEO score and a live Google SERP preview. | Meta Tag Analyzer किसी भी वेबपेज के raw HTML source को पढ़कर उसमें मौजूद हर SEO-संबंधी meta tag — title, description, canonical, robots, viewport, charset, language, Open Graph और Twitter Card tags — निकालता है, फिर पेज को 0–100 के SEO score और एक live Google SERP preview के साथ grade करता है।

How the SEO Score Is Calculated | SEO Score कैसे calculate होता है

The score rewards the presence and correct length of the most impactful tags: a title between 30–60 characters, a description between 70–160 characters, a canonical URL, a working og:image, viewport and charset tags, and a lang attribute each contribute points, while secondary tags like author or theme-color add smaller bonuses. A score above 80 means the page's meta tags are in solid shape; 40–79 means there are specific gaps worth fixing; below 40 usually means several load-bearing tags are missing entirely. | यह Score सबसे असरदार tags की मौजूदगी और सही length को reward करता है: 30–60 characters का title, 70–160 characters की description, एक canonical URL, एक काम करता og:image, viewport और charset tags, और एक lang attribute — इन सबसे points मिलते हैं, जबकि author या theme-color जैसे secondary tags से छोटे bonus points मिलते हैं। 80 से ऊपर का Score बताता है कि पेज के meta tags ठीक स्थिति में हैं; 40–79 का मतलब है कि कुछ खास कमियाँ ठीक करने लायक हैं; 40 से नीचे का मतलब अक्सर यह होता है कि कई ज़रूरी tags पूरी तरह गायब हैं।

Why Paste HTML Instead of Entering a URL | URL डालने के बजाय HTML Paste करने की वजह

Many online meta tag checkers ask for a live URL and then try to fetch that page's HTML from their own server — which routinely fails on pages protected by CORS restrictions, login walls, or firewalls, and exposes the page's content to a third-party server in the process. This tool instead asks you to view-source the page yourself (Ctrl+U) and paste the HTML directly, so it can analyze any page — public, staging, or behind a login — entirely inside your own browser. | कई online meta tag checkers एक live URL माँगते हैं और फिर उस पेज का HTML अपने server से fetch करने की कोशिश करते हैं — जो अक्सर CORS restrictions, login walls, या firewalls वाले pages पर fail हो जाता है, और इस प्रक्रिया में पेज का content किसी third-party server को भी दिखा देता है। यह टूल इसके बजाय आपसे पेज का view-source (Ctrl+U) करके HTML सीधे paste करने को कहता है, जिससे यह किसी भी पेज — public, staging, या login के पीछे वाले — को पूरी तरह आपके अपने browser के भीतर analyze कर सकता है।

Reading the Status Badges | Status Badges को समझना

Each detected tag is shown with a color-coded badge: green/OK means the tag is present and well-formed, yellow/Warning means it exists but could be improved (for example a description that's too short), red/Missing flags a tag that should be added, and the neutral info badge marks optional tags like meta keywords that search engines largely ignore today. The Tag Details list also shows a short tip under each row explaining exactly what to fix and why it matters. | हर पहचाने गए tag को एक color-coded badge के साथ दिखाया जाता है: हरा/OK मतलब tag मौजूद है और सही फॉर्मेट में है, पीला/Warning मतलब वह मौजूद है पर बेहतर हो सकता है (जैसे बहुत छोटी description), लाल/Missing उस tag को flag करता है जिसे जोड़ना चाहिए, और neutral info badge उन optional tags को दिखाता है जैसे meta keywords, जिन्हें आज search engines ज़्यादातर नज़रअंदाज़ कर देते हैं। Tag Details list में हर row के नीचे एक छोटा tip भी दिखता है जो बताता है कि क्या ठीक करना है और यह क्यों ज़रूरी है।

Frequently Asked Questions | अक्सर पूछे जाने वाले प्रश्न

Q. Why can't I just enter a URL instead of pasting HTML? | मैं URL क्यों नहीं डाल सकता, HTML paste क्यों करना पड़ता है?
Fetching a live URL from a server-side tool often fails due to CORS or login restrictions and sends your page's content to a third party; pasting HTML lets this tool analyze any page entirely in your browser. | किसी server-side tool से live URL fetch करना अक्सर CORS या login restrictions की वजह से fail हो जाता है और आपके पेज का content किसी तीसरे पक्ष को भेज देता है; HTML paste करने से यह टूल किसी भी पेज को पूरी तरह आपके browser में analyze कर सकता है।

Q. What does the SEO Score actually measure? | SEO Score असल में क्या मापता है?
It measures the presence and recommended length of the meta tags that most affect search and social appearance — title, description, canonical, viewport, charset, lang, and Open Graph image — out of 100 points. | यह उन meta tags की मौजूदगी और recommended length मापता है जो search और social appearance को सबसे ज़्यादा प्रभावित करते हैं — title, description, canonical, viewport, charset, lang, और Open Graph image — 100 में से points के रूप में।

Q. Why is my meta description marked "Too Long"? | मेरी meta description "Too Long" क्यों दिखाई जा रही है?
Google typically truncates descriptions beyond roughly 155–165 characters in search results, so anything longer than that is flagged so you can trim it before it gets cut off. | Google आमतौर पर search results में लगभग 155–165 characters से लंबी descriptions को truncate कर देता है, इसलिए इससे ज़्यादा लंबी description को flag किया जाता है ताकि आप उसे कटने से पहले छोटा कर सकें।

Q. Does Google actually use the meta keywords tag? | क्या Google असल में meta keywords tag का उपयोग करता है?
No — Google has ignored the meta keywords tag for ranking purposes for years, which is why this tool marks it as informational only rather than scoring it. | नहीं — Google कई सालों से ranking के लिए meta keywords tag को नज़रअंदाज़ करता है, इसलिए यह टूल इसे score करने के बजाय सिर्फ़ informational के रूप में दिखाता है।

Q. Why does og:image show as "Missing — Important"? | og:image "Missing — Important" क्यों दिखता है?
Without an og:image, Facebook, LinkedIn and WhatsApp will pick a random image from your page (or none at all) when your link is shared, so it's treated as a higher-priority fix than other Open Graph tags. | og:image के बिना, जब आपका link शेयर होता है तो Facebook, LinkedIn और WhatsApp आपके पेज से कोई random image उठा लेते हैं (या कोई image नहीं दिखाते), इसलिए इसे दूसरे Open Graph tags से ज़्यादा प्राथमिकता वाला fix माना जाता है।

Q. What happens if my Twitter Card tags are missing? | अगर मेरे Twitter Card tags गायब हों तो क्या होता है?
Twitter falls back to your Open Graph tags (og:title, og:description, og:image) automatically, so a missing twitter:title or twitter:description simply shows as informational rather than critical. | Twitter अपने आप आपके Open Graph tags (og:title, og:description, og:image) पर fallback कर लेता है, इसलिए गायब twitter:title या twitter:description critical की जगह informational दिखता है।

Q. My robots tag shows "noindex" — is that a problem? | मेरा robots tag "noindex" दिखा रहा है — क्या यह समस्या है?
It's only a problem if unintentional — noindex explicitly tells search engines not to list this page, so the tool highlights it in case you forgot it was set and want the page to actually rank. | यह समस्या तभी है जब यह जानबूझकर न किया गया हो — noindex सीधे search engines को बताता है कि इस पेज को list न करें, इसलिए टूल इसे highlight करता है ताकि अगर आप भूल गए हों और चाहते हों कि पेज rank करे, तो आप इसे ठीक कर सकें।

Q. Why does the title length show both characters and pixels? | Title length characters और pixels दोनों में क्यों दिखती है?
Characters alone are misleading because letters like "W" are much wider than "i" in Google's search result font — pixel width gives a far more accurate prediction of whether your title will actually get truncated. | सिर्फ़ characters भ्रामक हो सकते हैं क्योंकि "W" जैसा letter Google के search result font में "i" से कहीं ज़्यादा चौड़ा होता है — pixel width यह ज़्यादा सटीक अंदाज़ा देता है कि आपका title असल में truncate होगा या नहीं।
